# Alur

Algoritma, Logika, Uji, Rancang. App belajar berpikir komputasional untuk SD kelas 4-6, dipakai di kelas (proyektor dan perangkat kelas).

## Mulai cepat
```
npm install
npm test        # build + verifikasi semua soal + uji asap klik
npm run serve   # buka http://localhost:8000
```
Layani `dist/` lewat HTTPS agar service worker (mode offline) aktif.

## Dokumen
- `AGENTS.md`: panduan serah-terima untuk agent atau pengembang berikutnya (baca ini dulu).
- `docs/ROADMAP.md`: fase, langkah, dan kriteria selesai.
- `docs/KURIKULUM.md`: kerangka kompetensi, enam level, unit ekskul, proyek pameran.
